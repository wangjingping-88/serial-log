# 命令组配置交换

在“命令组 → 命令组设置”中，可以把命令组导出成独立的 `command-groups.json`，通过文件或现有多机协作网络分享给其他人。

## 文件导入和导出

1. 选择范围：“当前分类列表”“全部命令组”或“当前选中命令组”。
2. 点击“导出配置”，保存 JSON 文件。导出包含命令文本及顺序、换行符、转义开关、组内间隔、循环间隔、次数、无限循环开关及分类关系。
3. 对方打开自己的命令组设置，点击“导入配置”，选择文件。
4. 检查追加的命令组，重新选择本机目标串口，点击“保存设置”。

独立交换文件不携带原电脑串口目标、COM 口、运行任务、队列或其他工作区设置。导入生成新身份，同名命令组和列表自动加序号，不覆盖现有配置；取消设置不会应用导入内容。导入后的工作区自动保存方式保持不变，交换文件不会被后台自动改写。

文件带格式标记和版本，最大 1 MiB；不兼容版本、无效参数或分类引用会明确拒绝。

## 协作传输

1. 主机、发送方、接收方运行支持命令组传输的新版预览，并建立协作连接。
2. 发送方选择导出范围，点击“协作发送”，选择“电脑 / 工作区”，点击“发送”。
3. 收到回执后显示“对方已接收，等待其确认导入”。这只确认进入接收箱，不表示已经导入或执行。
4. 接收方在指定工作区打开“命令组设置 → 接收配置”，选择配置并“导入所选”，设置目标后保存。

支持主机发往从机、从机发往主机、从机经主机转发给另一个从机；按工作区精确投递，不要求共享串口或订阅日志。旧版不支持传输时不可选，原日志协作继续使用协议 3。

每个工作区的待确认接收箱最多 10 份，保留到本次应用退出；可以丢弃。取消命令组设置后仍保留接收配置，成功保存才移除已导入项。收到配置不会自动运行或改变串口连接。

断线、目标离线、格式错误、接收箱已满会提示失败；10 秒没有回执时提示先检查对方接收箱再重发，避免重复导入。当前版本不自动重发，也不补传离线配置。

## 工作区配置快照

工作区菜单新增“导出当前工作区快照”“从快照新建工作区”“协作发送当前工作区”和“接收工作区快照”。采用用户主动发送的快照方式，不持续同步后续修改。

- 快照保留本地窗口名称和波特率、布局、命令及分类、命令目标逻辑关系、队列配置、主题、快捷键和 Ymodem 规则。文件最大 4 MiB，命令组部分仍遵循命令组配置限制。
- 接收方确认后新建独立工作区，同名自动添加序号，工作区／窗口／命令组／列表及队列身份重新分配，对应引用一起更新。
- 清除来源电脑的 COM 映射、共享开关、协作连接参数和订阅，以及固件／命令文件路径。日志使用接收电脑当前工作区的日志根目录，电脑身份使用本机身份。
- 不包含日志文件或固件文件，不复制运行状态，不自动连接、发送、烧录或开启协作；命令目标仍对应导入的窗口，接收方先为窗口选择实际 COM 口。
- 新建后仍停留在当前工作区，已有测试继续运行。手动切换到新工作区进行配置。
- 协作接收箱每个工作区最多保留 5 份快照，只保留至本次应用退出；成功新建并保存后才移除收到的快照。

## 验证范围

自动化回归覆盖参数及中文／转义内容往返、分类引用重映射、同名追加、清除目标、无效格式和大小限制、工作区导入不自动执行，以及真实本机 TCP 的三种定向传输和回执路径。跨电脑网络与实际操作仍需用预览验证。
