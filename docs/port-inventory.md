# 本机串口管理

点击 Serial Log 顶部菜单栏的「串口」，直接打开管理窗口。已有其他菜单展开时，鼠标滑到「串口」可以切换到其菜单，选择「串口管理…」打开窗口。管理窗口和日志窗口下拉框共用本机端口清单。关闭管理窗口不停止监测，退出 Serial Log 才停止。

## 清单与插拔提示

- 清单显示 COM 号、设备、厂商、驱动服务、别名、分组及相关工作区／窗口。搜索支持普通文本和 `/表达式/ims`，例如 `/COM(7|8)$/i`。
- 支持新建、编辑、删除分组，编辑分组颜色，将设备移入或移出分组。没有搜索过滤时可通过「上移／下移」排序，顺序按当前分类保存。
- 设备别名优先使用 Windows PnP 实例标识。实例标识是否随设备换接口保持不变取决于驱动与硬件；无可靠标识时可按 COM 保存，换设备后需核对。已有工作区不会自动改绑端口。
- 「定位窗口」定位所选工作区的现有配置；同口有多个窗口时先选择。「加入当前工作区」仅创建窗口并填入 COM 与建议名称，不自动连接、抢占其他工作区的端口或加入单条命令发送目标。
- 已配置但缺失的端口仍保留在工作区；清单中的「仅配置」不表示端口已打开。「外部占用未知」不等于空闲，监测不会通过试开串口获取占用情况。
- 「串口插拔时弹框提示」首次默认开启。在串口管理窗口取消勾选后，当前气泡立即收起，监测和事件记录继续。短时间内的变更合并显示；「最近事件」只保留本次运行最近 80 条，可清空。应用最小化时仍可显示非模态气泡。

## 导入原工具配置

1. 在原串口管理工具的 `data` 中找到 `port-aliases.json`、`port-groups.json`，主文件损坏时可选对应的 `.bak`。同一类型只选主文件或备份之一。
2. 使用「导入旧配置」，预览别名、分组、排序、仅按 COM 匹配的条目和冲突数量。若有冲突，选择保留本机值或用导入值覆盖冲突，取消不写入。
3. 成功后保存到 Serial Log 的 `data\port-inventory.json`，旧工具配置不改动。设置使用原子写入及备份；不兼容版本不覆盖。

本机别名、分组及弹框偏好不包含在工作区快照或协作消息中。端口下拉仍保存原始 COM 号，别名只是显示。设备检测和平时的串口接收、发送、自动重连、烧录互相独立。

## 实机验收

- 启动时已有串口不触发弹框；USB Hub 多口插拔后，核对清单、下拉、合并气泡和事件历史。关闭开关后再次插拔，确认历史仍更新且不弹框，重启后仍关闭。
- 如同一 USB 设备换接口或 COM 被另一设备复用，核对标识、别名与分组。非常短、未被系统清单采样观察到的变化可能不进入历史；扫描失败不会误报全拔出。
- 两个工作区采集、重连或烧录时操作管理窗口，确认监测不创建串口句柄、不打断接收、不自动修改目标；Windows 版本、驱动组合和多屏气泡定位需实机确认。
