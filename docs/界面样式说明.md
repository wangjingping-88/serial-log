# 现代 Windows 浅色控件样式

## 设计与范围

本次使用 UI/UX 与界面设计技能的稳定布局、可读性和克制反馈原则：以浅灰底、白色内容、细边框和工作区强调色统一控件，不改变菜单顺序、区域比例、窗口尺寸或命令组行高。不引入控件库、字体包、深色模式或新配置项，已纳入 v0.4.0 发布准备。

| 用途 | 基础颜色 |
|---|---|
| 页面／面板／次级底色 | `#F3F5F8`／`#FFFFFF`／`#F7F8FA` |
| 内容边界／输入边界 | `#D6DCE5`／`#8995A5` |
| 正文／辅助文字 | `#1F2937`／`#5F6B7A` |
| 危险文字／底色 | `#B42318`／`#FFF1F0` |

保留微软雅黑 UI、原有字号、日志 Consolas 字体及正常模式的日志等级颜色。输入框和下拉内容用常规字重；按钮、标题的既有尺寸约束保持不变。连接、保存等主要操作采用浅主题色底和深主题色文字，危险操作浅红底，其他按钮中性底色；控件圆角 4px、面板 6px。

## 交互与主题

- 输入框保留原生文本宿主；下拉框保留编辑部件、弹出部件、只读状态和双向文本绑定。可编辑下拉只让内部编辑框进入 Tab 顺序，避免两次停留。
- 复选框保留原有 16px 槽位，在内部绘制 13px 方框和白色三态标记。页签使用较清晰的中性边框，选中时主题色描边与底部强调线同时显示；保留原生选中态占位，避免页签位置或内容区域发生变化。
- 列表保留紧凑行高、选中、右键、拖动、双击编辑及 Delete 行为；命令组和队列固定滚动条预留继续有效。日志列表不应用新的逐行反馈动画。
- 悬停、释放和焦点过渡 180ms，按压 80ms，使用缓出曲线；加大正常／悬停／按压的底色差异，只动画独立状态层的透明度。不修改共享画刷，不动画布局属性。禁用和输入错误立即清除反馈；卸载时解绑事件并取消动画。
- 跟随 Windows 客户区动画设置；关闭动画或使用系统高对比度时直接显示最终状态。进度条仍由实际 Value 驱动，不添加扫光；不定进度保留 IsIndeterminate 语义，用低强调填充配合原有阶段文字提示。
- 主题资源按窗口保存；主窗口跟随当前工作区，弹窗在打开时捕获所属窗口颜色，不把当前工作区色写入 Application 全局资源。菜单、提示和下拉继续使用 Windows 原生阴影。
- 自定义主题色保持原值。2026-10-22 起主要按钮采用白底混合 18% 主题色，悬停／按压分别为 26%／34%，避免深色块过于抢眼；文字使用派生深主题色，并确保三个状态下文字对比度至少 4.5:1。浅底白字方案经实际预览确认难以辨认，已撤回。选中勾选框保留实心主题底和白色标记，设备配色不受影响。系统高对比度继续使用系统窗口、文字和选中颜色。

## 回归与发布边界

“帮助 → 关于”已替换为工具自有 WPF 弹窗，与检查更新使用相同的浅灰底、白色内容卡片、主题色按钮及原生窗口阴影。支持 Enter／Esc 关闭，并捕获打开时的工作区主题。

保留现有串口健康检查、协作、命令队列、工作区隔离及 Ymodem 回归；新增主题对比度、弹窗快照隔离、高对比度配色、波特率选择和文本绑定、中文输入开关、三态勾选、菜单契约、状态层清理、进度值和布局基线测试。

仅覆盖工程目录 `publish-latest` 的程序文件，发布脚本检查预览已关闭，保留完整 `data` 并校验目录、文件大小和 SHA256。不自动启动测试、不提交、不推送、不发布正式 Release。
