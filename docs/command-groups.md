# 命令组与发送说明

所有命令、目标、队列和发送设置只属于当前工作区。本文描述 v0.4.0 功能；目前处于发布准备阶段，尚未发布正式版本。

## 设置与导入

“命令组”页签外层展示命令组列表和执行队列，点击“命令组设置”打开独立编辑窗口。

### 按设备分类列表

- 外层保留“单条命令／命令组／Ymodem”。在“命令组”里面，用“全部／AP设备／IOT设备”等分类页签切换列表，页签名称和数量跟随配置。
- 通过“命令组设置”顶部新建、重命名、删除命名列表，左移／右移调整分类页签顺序。列表名称不能为空或重复；“全部”不可改名、删除，命名列表可以全部删除，不自动生成默认分类。
- 同一命令组可以加入多个列表，显示的是同一份命令、目标及执行状态，不会复制命令组。列表名不同于组名，不会改变串口目标。
- 选定命名列表后点“成员设置”，按组名搜索、多选增加或移除成员；也可以编辑单个组的“所属列表”勾选。未加入任何列表的组仍能在“全部”找到。
- 在命名列表中按 Delete 或右键“从当前列表移除”，仅移除分类关系，其他列表和队列不受影响。“全部”中的单组删除仍为真实删除。外层不再提供批量清空，只能在“命令组设置”中使用“清空列表”。
- 新建组归入当前命名列表；在“全部”中新建或导入不自动加入任何分类。组复制保留多列表关系，跨工作区导入只加入当前命名列表，不照搬来源分类或目标。
- 运行勾选组、停止组任务仅针对当前可见列表；切换列表不停止任务。当前工作区仍共用一个执行队列，可混合各列表的组，队列不随分类切换或成员移除而变化。同一组不能重复并行启动，同一串口仍互斥。
- 设置里可按名称搜索当前列表。组排序仍为工作区统一顺序，分类只是对这个顺序进行筛选；共享组的顺序和内容不是独立副本。上移、下移、智能分组只处理当前可见组，其他组保持相对顺序，队列不变。
- 分类、成员关系及当前所选列表随所属工作区保存，取消设置不影响原配置。旧命令组完整保留在“全部”；旧预览自动生成且未重命名的“默认列表”会迁除，不删除命令和队列，先备份再原子写入。用户重命名或手动创建的分类保留。配置格式仍为 5；工作区复制重新生成列表及组 ID 并重映射成员关系。
- 设置窗口默认放大为 1320×920（逻辑像素），按屏幕工作区缩小，留出屏幕边距。左侧组设置、右侧命令列表等宽，各占一半，中间留 10px 间隔。常规设置不出现页面滚动条；小屏和大量条目保留滚动兜底，命令顺序和命令内容列表自身仍可滚动。

- 设置支持新建、复制、删除，编辑名称、目标窗口、命令、换行符、组内间隔、循环间隔、循环次数、无限循环勾选及转义开关。
- 命令支持双击或右键编辑，右键或 `Ctrl+C` 复制完整命令，右键或 `Delete` 删除，拖动排序。相同文本的多行按行索引操作，不会误改第一条。
- 命令编辑框打开时默认全选，活动端和视图定位在命令开头；长命令不会因全选而自动滚动到末尾。导入命令编辑采用相同行为。
- “从其他工作区导入”选择来源工作区，使用 `Ctrl`／`Shift` 多选命令组或全选。复制命令和参数，生成新身份；来源保持不变，同名自动添加后缀。
- 跨工作区导入不沿用来源目标、不导入运行状态或队列。请重新勾选当前工作区目标，避免误发到其他测试设备。
- “复制”保留当前工作区目标和参数，生成新的命令组身份。
- 设置窗口改用常显、可滚动的命令组列表；点击“上移／下移”后保持当前项选中并滚动到可见范围，旁边显示“第几／共几组”，无需反复展开下拉框。保存设置后更新外层列表，外层不提供调序操作。
- “智能分组”把目标窗口集合完全相同的命令组相邻排列。按稳定窗口 ID 匹配，忽略名称和勾选顺序；同类组保持原先后顺序，各类按首次出现顺序排列，未选目标的组置后。只调序，不合并命令、不修改目标、参数、运行状态及执行队列；取消不应用，保存后持久化。
- 修改在“保存设置”后生效，“取消”丢弃编辑副本。窗口重命名会同步刷新目标名称，不改变勾选状态。

## 直接执行与并行

每组只占紧凑的一行，名称、参数摘要、状态与操作按钮同一行显示；长文本显示省略号，可通过提示查看完整内容。页签、命令组列表和执行队列的数量直接显示在各自标题后，增删时立即更新，不额外占用列表高度。分类页签与工具按钮共用一行。命名列表仅移除成员；在“全部”中选中组后按 `Delete` 或右键“删除”，确认后真实删除；外层不再显示删除按钮。

命令组列表和执行队列固定预留垂直滚动条空间，分类切换、条目增减或清空时不改变内容宽度，各列和按钮保持原位。无需滚动时滑块隐藏且不响应点击，需要滚动时正常显示。

双击名称、参数摘要、执行状态或该行的其他非交互区域，直接打开命令组设置并选中被双击的组。名称文字与勾选框分离，双击编辑不会改变并行运行的勾选；勾选框和“运行／入队”按钮仍执行原操作，列表空白和执行队列不触发编辑。行尾仅提供：

- “运行”：未勾选无限循环时按配置次数执行；`0` 表示不循环，只执行一轮。
- “入队”：加入队列，暂不启动发送。勾选无限循环的组按钮置灰，悬停仍可查看禁止入队的原因；修改勾选后立即更新可用状态。

单条命令与命令组统一采用：循环次数 `0` 表示不循环、只执行一轮；正数表示总执行轮次，`1` 也只执行一轮。“无限循环”须单独勾选，勾选后次数输入置灰并忽略原值，取消勾选恢复该值。循环间隔 `0` 只表示轮次之间不等待。旧配置缺少该开关时默认不勾选，不会因次数为 `0` 自动变为无限。列表中的“无限循环”是配置摘要，右侧“就绪”表示任务尚未启动。

批量清空入口仅位于“命令组设置”顶部的“清空列表”：命名列表仅清空分类关系；“全部”删除空闲命令组及其队列引用，也会从其他分类中移除这些组。操作先确认，再修改编辑草稿；保存设置后才应用到所属工作区，取消则保留原组及队列。所属工作区正在运行或被运行中队列引用的组会保留，不隐式停止任务。外层只保留执行队列自己的“清空”。状态列左移并扩大，常见完成统计可以完整显示，超长错误仍可通过提示查看。

勾选多个组后点击“并行运行勾选组”。不同串口可以并行；包含同一串口的后启动组立即提示冲突，不自动等待或重试，未冲突的其他组继续运行。若目标被单条命令循环或 Ymodem 烧录占用，也会提示先停止相关任务。

目标必须存在、已连接、允许发送，命令列表不能为空。各组显示独立状态，发送异常或目标失效后停止该组后续轮次；已经开始的一轮仍沿用原命令发送逻辑。“停止组任务”只请求停止当前列表的组任务；队列有独立“停止队列”入口，不停止其他工作区或单条命令循环。

## 执行队列

点击组的“入队”按顺序追加条目。同一组可以重复入队，每个条目拥有独立身份；重复条目不会合并。

1. 按需要的执行顺序逐项加入；外层不提供上下移动按钮，可选中条目按 `Delete` 或右键“删除”，再重新加入末尾。队列不显示单独的删除按钮。
2. 点击“执行队列”，按条目顺序执行。
3. 每项按该组配置的循环次数运行，完成后才开始下一项。
4. 勾选无限循环的组不能入队；入队后若勾选无限，队列启动时也会拒绝。次数为 `0` 且未勾选无限的组允许入队，执行一轮。
5. 遇到目标无效、发送失败、串口冲突或取消时停止，不运行后续条目；明确显示停止位置。

队列底部“清空”只移除当前工作区的队列条目，不删除命令组。队列运行中禁止添加、删除及清空，需要先停止。完成或停止后条目继续保留，可增删并再次执行。命令组设置中的排序不会改变已经加入的队列顺序。删除空闲命令组时会确认，并移除所有引用该组的队列条目。

## 配置快照与后台运行

直接运行在启动时生成配置和目标快照；队列在启动时对所有条目生成快照。因此编辑、重命名、调序或切换工作区不会悄悄改变正在执行的命令。运行中的组，以及正在运行的队列所引用的组，不允许删除。

隐藏、浮动、切换工作区不取消后台任务。停止工作区、删除目标、转移串口和退出应用沿用原确认流程，并等待涉及目标的发送停止；其他工作区及无关组继续运行。

组分类、成员关系、列表顺序、队列顺序、所选组和参数保存在工具目录 `data\workspace.json`。配置格式升级至 5，先备份再原子写入；重命名通过稳定 ID 保留队列引用。无限循环开关按工作区保存，组复制和跨工作区导入会保留该设置。任务启动后使用次数和无限开关的快照，不因编辑而改变正在运行的任务。重启只恢复配置，不自动执行任务。

## 转义发送

单条命令和每个命令组均有“解析转义字符”开关，默认开启：

| 输入 | 实际发送 |
|---|---|
| `\r` | 回车 CR，`0D` |
| `\n` | 换行 LF，`0A` |
| `\t` | 制表符 TAB，`09` |
| `\\` | 一个字面量反斜杠 |

未知转义（如 `\x`）和末尾单反斜杠保持原样。不支持用 `\xNN` 构造 Hex 二进制包。中文继续使用现有 UTF-8 串口发送。

例如输入：

```text
at+wiotasend=10000,12\r\n0123456789
```

会在一次串口写入中发送命令、实际 CRLF 和数据，不拆成两次人工发送。解析后仍在末尾追加所选 `Cr`／`Lf`／`CrLf`；若数据末尾不能有附加换行，选择 `None`。设备对长度、数据和命令参数的要求仍需自行确认，工具不猜测或更改参数。

关闭开关则原样发送 `\r\n` 文字。直接运行及队列都会保留启动时的转义设置，运行中修改开关不影响已启动的任务。

## 本地发送回显

“日志 → 本地发送回显”开关默认开启，按工作区保存。单条发送、循环、命令组和队列的实际串口写入成功后，在该目标日志显示带时间戳的 `[SerialLog] [发送]` 记录。

内部换行显示为 `\r`／`\n`，避免回显占据多行；末尾换行不展示。记录沿用现有显示、自动保存及共享链路，不当作设备接收活动刷新串口健康状态。

回显仅表示写入成功，不代表设备已接收、执行或返回成功。实际设备回包仍是独立日志。失败写入不显示成功回显；远程命令请求不在请求端伪造回显，源端实际发送后可通过共享日志看到；Ymodem 规则和二进制数据包不进入普通发送回显。

## 本轮回归

- 模拟串口覆盖同端口互斥、并行执行、次数、队列顺序/重复/删除、取消释放、配置快照及工作区隔离。
- 覆盖组复制、跨工作区导入、目标名称原地更新、持久化与备份迁移。
- 转义后的命令和数据验证为一次写入，发送失败不生成成功回显。
- 使用应用实际样式渲染列表与设置窗口；在宽窄布局下反复切换单条／命令组／Ymodem，比较所有目标坐标、行高和字体完全一致。
- 验证无限循环入队按钮实际置灰、禁用时的悬停说明、修改无限开关后的立即刷新；验证标题计数跟随增删、紧凑区域可显示多行，右键和 Delete 只删除当前工作区点选的组或队列条目。
- 验证 0 次单轮、正数轮次、显式无限、单条与命令组快照、空闲组清空保护、队列清空禁用及工作区隔离。
- 分类回归覆盖多个列表共享同一组、成员移除／清空／删除分类不丢命令及队列、搜索和中文名称、草稿取消／保存、迁移备份、非法引用拒绝、工作区复制 ID 重映射、跨列表后台运行及窄屏布局；另覆盖无默认分类、最后分类删除、旧默认分类安全迁除、等宽设置窗口、外层无清空入口及设置草稿运行保护。
- 使用原生及应用精简滚动样式，在宽窄布局中反复切换溢出／短列表，并验证空列表、新增条目及队列增减时内容宽度和各列坐标不变；无溢出时不显示假滑块。当前 Release 全量 434 项通过。

界面与模拟回归不能替代实机串口验收，下一步在预览中验证多设备执行、取消、设备接收数据以及浮动命令区操作。
