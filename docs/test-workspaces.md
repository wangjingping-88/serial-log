# 测试工作区与按需协作

## 使用范围

标题栏可选择工作区，通过“工作区”菜单新建、复制、重命名、删除或停止当前工作区。下拉列表显示各工作区的本地连接数及循环发送状态。

页面、连接全部／断开全部、主题、视图、日志、快捷键和命令操作均绑定当前工作区。切换只更换显示实例，后台串口接收、日志保存、循环发送和协作连接继续运行。浮动命令面板切换时关闭显示，再按目标工作区的浮动设置恢复，不销毁命令运行实例。

退出和安装更新属于整个应用的操作，会列出正在运行的工作区并要求确认。没有“停止所有工作区”的测试菜单。

## 串口占用与转移

应用内手动连接、批量连接及自动重连共用端口租约。同一个串口不允许被两个窗口同时打开。实际连接冲突时提示原工作区和窗口；拒绝转移会保留原连接。批量连接先汇总已占用端口，让用户选择需要转移的项目。

转移先取消原窗口的重连意图与等待中的连接请求，停止涉及该窗口的循环，再等待在途发送、打开操作和驱动关闭。释放失败时不会授权新窗口打开。原窗口保留配置与历史，但不会自动抢回端口。

“停止当前工作区”停止该工作区的循环、串口、协作及重连意图，不删除配置或历史文件。

## 共享与订阅

本地窗口右侧增加“共享”复选框，与发送目标和自动保存独立。新建、复制及旧配置迁入的本地窗口默认不共享。协作菜单可批量共享或取消当前工作区的共享。

“协作 → 订阅窗口”按电脑、工作区和窗口展示共享目录，可搜索及多选。默认不订阅；只订阅的窗口进入页面，并根据接收端该窗口的自动保存设置落盘。

取消共享后，订阅端保留历史窗口并标记“对方已停止共享”。重新共享或重新连接后恢复原订阅。取消订阅移除当前工作区中的显示窗口，但不删除文件；再次订阅只接收新的实时日志。

协作协议版本为 3。电脑身份与工作区身份共同区分连接，同一电脑不同工作区可连接同一主机。本机多个主机工作区需使用不同监听端口；端口冲突不会关闭另一个工作区的服务。旧协议连接会明确报不兼容。

主机分发共享目录，按订阅关系转发日志。未订阅的日志不进入主机显示及保存队列。主机向从机发送命令时校验目标工作区、窗口、共享及连接状态。

## 配置与日志

- 配置文件仍为工具目录下的 `data\workspace.json`。
- 新容器格式 `FormatVersion: 2`，包括 `CurrentWorkspaceId` 和 `Workspaces`；各工作区的配置保存在 `Configuration` 中。
- 首次读取旧格式时，先创建 `workspace.json.legacy-日期-随机身份.bak` 原始备份，再通过临时文件和原子替换保存。解析、验证或替换失败不会重置原文件。
- 旧配置迁入“默认测试”，保留已有本地窗口身份、命令及目标关系。
- 复制工作区生成新的工作区和本地窗口身份，重新映射命令目标；不复制连接、发送任务或本地共享启用状态。
- 日志路径为“配置的根目录／工作区 ID／日志批次”。重命名不搬动旧日志，删除工作区不删除日志。
- 重启恢复配置和最后选中的工作区，不自动连接串口或启动命令循环。启动协作后恢复保存的订阅。

## 验证记录

本次新增配置迁移、原子替换失败保护、配置复制、工作区菜单隔离、后台循环、订阅隔离、端口竞争与失败保护测试，以及真实 TCP 回环网络上的多电脑身份／多工作区协议测试。原有虚拟化日志、串口健康检查和失效句柄回归继续执行。

v0.3.0 发布准备验证：Release 全量测试 273 项通过，全量构建 0 警告、0 错误。测试结果保存在本地 `artifacts/test-results/v0.3.0`。初始工作区预览验证为 253 项，后续增加了名称输入、菜单状态、放大占位分页及退出清理回归。

预览启动检查：独立暂存目录下的程序正常创建窗口、保持响应并接受关闭，生成格式版本 2 的单个空白工作区；未连接真实串口。程序文件复制到预览目标后已校验哈希一致。

尚需实机验收：实际 USB 驱动释放与转移、三台物理电脑的共享订阅组合、长时间后台采集、窗口阴影和低分辨率布局。TCP 回环及模拟端口租约测试不能替代这些硬件验证。

## 预览与回退注意

预览目标为 `D:\serial-log-data\publish-latest`，只更新程序文件，不能清空或镜像删除目标的 `data`。当前正式安装目录不在发布范围内。

本次发布前该预览目录不存在，因此没有可保留的旧数据，首次打开为新的空白工作区。正在运行的 `D:\tools\SerialLog` 及其数据未修改。需要用真实配置验证迁移时，先关闭正式版，再将其 `data\workspace.json` 的副本放入预览目录的 `data`；保留正式版原文件。

应用版本为 v0.3.0，协议 3 需要协作参与方统一升级；不要让旧版本读取已经迁移的新格式配置。需要回到旧版本时，使用迁移前的备份，勿覆盖唯一一份新配置。

跨电脑复制完整 data 会复制电脑身份。若双方身份相同，会将对方当作自己过滤，出现 TCP 已连接但订阅目录为空。当前尚未自动修复此冲突，应确保每台电脑使用独立电脑 ID；无需删除工作区和日志配置。
