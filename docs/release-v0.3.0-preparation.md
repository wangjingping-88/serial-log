# v0.3.0 发布准备

## 本次范围

主版本变化为测试工作区隔离、协议 3 按需共享订阅、应用级串口占用管理。另包含本轮实机反馈的菜单显示和间距、中文输入、统一确认弹框、放大占位分页、异步退出清理修正。

正式发布正文：`.github/release-notes.md`；使用说明：`docs/test-workspaces.md`、README 和在线帮助源文件。应用版本为 0.3.0，程序集及文件版本为 0.3.0.0，协作协议为 3，配置容器格式为 2。

## 兼容性与验证边界

- 协议 3 不兼容旧协议，协作电脑应同时升级。
- 旧配置先备份再原子迁移，旧版不能读取新容器格式；回退使用迁移前备份。
- 跨电脑直接复制 data 可能复制电脑身份；自动识别并修复身份冲突尚未实现，发布说明明确提示此限制。
- 用户已反馈当前预览使用无明显问题；自动化测试不能替代所有 USB 驱动、第三方输入法和长时间多机验证。
- 正式发布包必须从干净目录生成，不携带任何 data、串口日志或用户配置；必须包含单文件更新助手。
